# Mohcin Mekhfioui Academic Portfolio

Professional one-page academic portfolio prepared for GitHub Pages.

## Publish on GitHub Pages

1. Open the repository `mekhfioui/mekhfioui.github.io`.
2. Upload every file and folder located inside `dist/` to the repository root.
3. Keep `index.html` at the repository root.
4. In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/(root)`.
5. Open `https://mekhfioui.github.io/` after GitHub finishes the deployment.

## Main files

- `index.html` — complete website
- `assets/mohcin-mekhfioui.jpg` — portrait
- `assets/Mohcin_Mekhfioui_CV.pdf` — downloadable CV
- `robots.txt` and `sitemap.xml` — search-engine discovery

## Updating the site

Edit the text in `index.html`, commit the change, and GitHub Pages will publish it automatically.
